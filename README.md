🚀 How to Run the Project Locally
📦 1. Clone the Repository
🛠 2. Install Dependencies
     -composer install
     -npm install

🔐 3. Generate Application Key
     -php artisan key:generate
     
🧬 4. Run Migrations
     -php artisan migrate

5. Seed the Database
     -php artisan db:seed

🎨 6. Build Frontend Assets
     -npm run dev

npm run build
▶️ 7. Serve the Application
     -php artisan serve
